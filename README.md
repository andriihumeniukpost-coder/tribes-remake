# Prehistoric Tribes: Remake

Ремейк на C++17 + SDL2, окно 640x480, управление под R36S.

## Сборка на ПК
    cmake -S . -B build && cmake --build build
    ./build/tribes                       # стрелки, Z=A, X=B, A=X, S=Y, Enter=Start, правый Shift=Select
    ./build/tribes --headless --frames 300 --script "20:X 40:A" --shots "100:out.png"   # без окна, для тестов

## Структура
- `data/*.json` — все правила: здания, юниты (катапульта, таран...), умения, эпохи, главы. Правится без перекомпиляции.
- `src/gfx.*` — отрисовка, текст (TTF, кириллица), кнопки геймпада в подсказках.
- `src/game.*` — карта, жители, строительство, дерево умений, смена эпох.
- `src/input.hpp` — логические кнопки R36S (D-pad, A, B, X, Y, L1, R1, L2, R2, Start, Select).

## Сделано
Карта и камера, добровольные добытчики дерева и камня, строительство из меню, еда и рост населения,
эпохи (условия в `Game::tryAdvanceEra`), экран умений (3 ветки), подсказки кнопок.

## Бой (есть)
- Обучение: встаньте на здание с кнопкой «Обучить» (A): оружейная — метатель/копейщик, мастерская — катапульта, загон — мамонт.
- Волны врагов по времени из `data/waves.json`. Бойцы держатся у хижины вождя и защищают её.
- Катапульта бьёт по площади (splash) и с мин. дистанции. Здания имеют HP; разрушенная хижина вождя = поражение.
- Касания: виртуальный геймпад появляется при первом касании (или с `--touch`).

Отладка: `--debug` (ресурсы, эпоха 5, все умения), `--touch` (показать кнопки), `--headless --script ... --shots ...`.

## Дальше
Баланс боя, сохранения, главы 6-10, касания по карте (тап для выбора клетки), спрайты 640x480, звук, сборка под aarch64 и Android.

## Android (APK)
Сборка делается в GitHub Actions (`.github/workflows/android.yml`): APK скачивается из раздела Actions → app-debug.apk.
Локально: нужны Android SDK, NDK 26.1, CMake 3.22; клон SDL2 в `android/app/src/main/cpp/SDL`; данные в `android/app/src/main/assets/data` и `.../assets/assets`.
